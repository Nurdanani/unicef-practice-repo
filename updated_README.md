# Komek — On-Demand Errand & Task Marketplace

Komek is an on-demand marketplace that connects people who need help with everyday tasks with people who are ready to complete them.

The platform is designed for users in Almaty, Kazakhstan.

## Main Features

- Create tasks with a title, description, category, location, deadline, and reward.
- Browse available tasks.
- Make offers to complete tasks.
- Choose one offer from available runners.
- Track task status: Open, Accepted, In Progress, and Done.
- Rate users after task completion.

## Task Categories

- Pickup
- Queue
- Buy
- Dog Walking
- Other

## Project Purpose

Komek aims to make everyday tasks easier by connecting people who need assistance with those who can help.

This project was developed as part of a university IT Project Management course.
